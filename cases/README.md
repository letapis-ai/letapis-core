# Cases

Things that actually happened, written up so the next person does not have to work them out
again. Each case is one situation: what the engine reported, what it turned out to be, what was
done about it, and what the numbers looked like before and after.

These are not tutorials. A tutorial shows the happy path; a case shows a real corpus with real
damage in it, including the parts that were left alone on purpose.
